WAD 2 Final Project: Laravel Application By Pair
Instruction:
Create your own Laravel application from scratch or by modifying an existing CRUD project. You are free to choose any concept (e.g., task manager, booking system, inventory, etc.), as long as all required concepts are properly implemented.
Your goal is to build a working system that demonstrates proper use of core Laravel features, not just a basic CRUD.
Expected Output
A functional web application that:
Allows users to interact with data through a complete CRUD flow
Restricts access based on login and roles
Enforces proper ownership and permissions
Uses database relationships correctly
Required Features
1. CRUD Operations
2. Authentication
3. Middleware
4. Authorization (Gates, Policies, and Service Providers)
5. Eloquent Relationships
Evaluation Focus
Your project will be checked based on:
Correct use of each required concept
Proper restriction of access and actions
Clean and logical structure of models and relationships
Functionality (the system should work without errors)
Submission Requirements
GitHub repository link
README containing:
Project title
Description of the system
List of implemented features
Screen Record showing:
All functionalities and features
